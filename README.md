# 미팅메이트 (Meeting Mate)

> 비즈니스 미팅은 그대로, **통역·녹음·요약·표현 스터디**는 여기서.

구글 실시간 번역 기반의 미팅 코파일럿 PWA입니다. 상대의 영어와 내 한국어를 실시간 자막으로 바꾸고, 미팅을 자동 녹음해 종료와 동시에 요약·액션 아이템·비즈니스 표현을 뽑아 스터디 카드로 남깁니다.

- 앱: https://danielsonghoon-sketch.github.io/meeting-mate/
- 저장소: https://github.com/danielsonghoon-sketch/meeting-mate

## 기능

### 1. 실시간 자막 · 번역
- Web Speech API(`SpeechRecognition`, `continuous`, `interimResults`)로 실시간 음성 인식.
- **말하는 중 실시간 동시 번역(구글 번역 대화 모드)** — 말이 끝나기 전 `interim` 자막이 커다란 카드로 뜨고, 그 아래에 번역문이 0.4초 쓰로틀로 따라붙습니다. 원문 위·번역 아래, 말하는 동안 글자가 채워지고 번역이 동시에 흐릅니다. 확정되면 확정 카드가 같은 번역을 지연 없이(캐시) 이어받습니다.
- 자막 도구줄의 **인식 상태 배지**가 `듣는 중… / 인식 재연결 중… / 무음 8초 / 자막 꺼짐`으로 실시간 상태를 보여 줍니다. 번역이 실패하면 말하는 중 카드에 `번역 실패 · 탭해서 다시 시도`와 원인(HTTP 코드·연결 오류)이 바로 표시됩니다.
- **번역 방향 버튼 3가지** — 홈·설정·미팅 화면 어디서나 같은 버튼으로 바꾸고 바로 저장됩니다.
  - **영 → 한 (EN → KO)**: 영어만 인식해 한국어 자막.
  - **한 → 영 (KO → EN)**: 한국어만 인식해 영어 자막.
  - **양방향 자동 (한 ↔ 영)**: 인식된 문장에 한글이 있으면 `ko → en`, 영문이면 `en → ko`로 자동 번역. 미팅 중 **⇄ 버튼**(PC는 Tab)으로 주 인식 언어(EN/KO)를 1탭 전환.
- **상대 말하는 중(English → 한국어) / 내가 말하는 중(한국어 → English)** 버튼 1탭 전환. 방향을 고정한 모드에서는 반대쪽 버튼이 꺼지고, 탭하면 양방향 자동으로 바꾸라는 안내가 나옵니다.
- 번역 엔진: **Google Translate** 공개 엔드포인트(`translate.googleapis.com`(gtx) 1순위 → `clients5.google.com` 폴백, 두 곳 모두 실패하면 한 번만 재시도 후 실패 표시·문장별 재시도 버튼) 기본. OpenAI 키가 있으면 **GPT 통역 모드** 선택 가능.
- 자막마다 방향 태그(`EN→KO` / `KO→EN`) · ★(스터디 저장) · 다시 듣기(TTS). 실패한 문장은 탭해서 재번역.
- 방향은 `meetingmate.settings.v1`의 `dirMode`(`auto`/`en2ko`/`ko2en`)에 저장되어 다음 실행에도 유지됩니다.

### 1-1. 한국어 회의록 모드 (🇰🇷 번역 없음)
- 홈·미팅 화면의 **모드 버튼**(`🇰🇷 한국어 회의록` / `🌐 실시간 통역`)으로 1탭 전환하고, 미팅 중에도 바로 바꿀 수 있습니다(설정에도 같은 버튼).
- 이 모드에서는 음성 인식이 **`ko-KR`로 고정**되고 **구글 번역을 호출하지 않습니다**(번역 요청 0건) — 자막이 빠르고 깔끔하게 한국어 원문만 쌓입니다.
- 미팅 중 번역 UI(`→ 번역문`, 영↔한 방향 버튼, ⇄ 전환, 발언자 버튼)를 숨기고 **한국어 자막 + ★ 중요 표시(회의록 강조용) + 녹음 타이머**만 남깁니다. ★는 영어 표현이 없으므로 스터디에 저장하지 않고, 회의록 요약 상단에 먼저 반영됩니다.
- 녹음 기본 ON·안드로이드 마이크 충돌 안전장치(자동 자막 우선 전환·1탭 녹음 끄기)는 통역 모드와 동일하게 동작합니다.
- 데모도 한국어 회의록 샘플(단가·납기·포장·샘플 발송·결제 조건)로 실행되어 1. 주요사항 요약 / 2. To-do가 바로 만들어집니다.

### 2. 자동 녹음 · 안드로이드 마이크 충돌 대응
- 미팅 시작과 동시에 `MediaRecorder`로 녹음(PC 기본 ON, 토글 가능), 일시정지/재개, 경과 타이머, 실시간 레벨 미터.
- **안드로이드 Chrome은 녹음(`getUserMedia`)이 마이크를 잡으면 음성 인식이 죽는 기기가 있습니다.** 그래서 ① 음성 인식을 먼저 켜고 녹음을 시작하며, ② 녹음을 끄면 `getUserMedia` 스트림까지 즉시 반납하고 음성 인식을 다시 켭니다(자막 유지). ③ 녹음 중인데 소리는 들어오는데 3초 넘게 인식 결과가 0건이면 마이크 충돌로 보고 **녹음을 자동으로 내려 자막·번역을 살리고**, 다음 미팅부터는 자막 우선으로 시작합니다. 6초 넘게 무음이면 상단 배너에 **[녹음 끄고 실시간 자막 켜기]** 1탭 버튼이 뜹니다. ④ 설정의 **실시간 자막 우선(모바일 권장)** 을 켜면 처음부터 마이크를 잡지 않고 자막만 켭니다. 녹음은 언제든 토글로 다시 켤 수 있습니다(PC는 녹음+자막 동시 동작).
- 마이크 + (선택) **시스템 오디오**를 WebAudio로 믹스해 한 파일로 녹음. PC 온라인 미팅에서 상대 목소리까지 담을 수 있습니다.
- 종료 후 앱 안에서 바로 재생(커스텀 플레이어)·다운로드. 오디오는 **IndexedDB**에 저장해 localStorage 용량 초과를 피합니다.

### 3. 자동 요약 · 회의록(.doc)
- 종료 시 자동 요약: **핵심 키워드** · 한눈에 보기(한 줄 핵심) · 주요 논의 · 결정 사항 · Action Items(담당/기한) · 고급 비즈니스 표현 5~10개.
- **키워드형 요약** — 장황한 서술 대신 한눈에 들어오는 키워드 스타일로 정리합니다(일반 통역 요약·한국어 회의록 공통).
  - 요약 맨 위에 **`#단가` `#납기` `#샘플` `#포장` `#결제`** 처럼 이번 회의의 핵심 키워드 칩이 붙어 주제가 바로 보입니다(회의 목록 카드에도 3개 표시).
  - 본문 항목은 **`키워드: 핵심 내용`** 형식의 짧은 불릿으로 압축됩니다 — 예: `납기: 주문 확정 후 45일 · 성수기 60일`, `결제: T/T 30일 확정`, `샘플: 다음 주 화요일까지 2세트 발송`. 원문에서 명사 키워드·수치·날짜·액션을 뽑아 `~했습니다` 같은 서술형 어미를 회의록 메모체로 다듬습니다.
  - To-do/액션 아이템에도 `샘플`·`계약`·`발송` 같은 키워드 라벨이 붙고, 담당·기한은 별도 칩으로 보여 줍니다.
  - GPT 요약(`gpt-4o-mini`)도 같은 규칙의 프롬프트로 `keywords` + `키워드: 내용` 형식만 돌려주도록 지시합니다(키워드가 비면 자막에서 자동 추출).
- **한국어 회의록 형식** — 한국어만 기록한 회의(한국어 회의록 모드, 번역문이 없는 한국어 회의)는 요약이 **1. 주요사항 요약**(핵심 요약 · 주요 논의 · 결정 사항 · ★ 중요 표시)과 **2. To-do**(체크리스트 · 담당 · 기한 · 완료 여부)로 정리되고, 그 아래에 **전체 발언 기록**이 붙습니다.
  - OpenAI 키가 있으면 `gpt-4o-mini`가 회의록 전용 프롬프트로 `1. 주요사항 요약`과 `2. To-do`를 정밀 추출합니다.
  - 키가 없어도 한국어 규칙 분석기가 핵심 문장 · 요청/약속 문장(`~하기/~확인/~진행/~발송/~회신/~까지`) · ★ 표시 문장을 우선 반영해 알차게 채웁니다(현황·추측 문장은 To-do에서 제외).
- **회의록 .doc 저장** — 요약 상세 화면의 **`회의록 .doc 저장`** 버튼으로 Word·한글(HWP)·구글 문서에서 바로 열리는 `.doc`을 내려받습니다. Word 호환 HTML(`application/msword;charset=utf-8`, UTF-8 BOM, A4 표 서식)로 만들고 파일명은 `회의록_YYYY-MM-DD_제목.doc`입니다. 회의 제목·일시·소요시간·**핵심 키워드**, 키워드 배지 줄, 1. 주요사항 요약(키워드형 불릿), 2. To-do(키워드 열 · 완료 여부 ☑/☐), 전체 발언 기록이 표와 제목으로 들어갑니다.
- **OpenAI 키가 없어도** 규칙/키워드 기반 요약 + 자막·요약 프롬프트 원탭 복사로 어디서나 사용 가능.
- OpenAI 키(`gpt-4o-mini`)가 있으면 문맥 기반 요약·표현 추출. 키는 이 기기 localStorage에만 저장되고 백업 JSON에는 포함되지 않습니다.

### 4. 표현 스터디
- 회의 중 ★ 즉시 저장, 요약 화면에서 표현별/전체 1탭 추가, 직접 추가.
- 출처 회의·날짜, 검색·필터(전체/미학습/학습 완료), **발음 듣기 1.0x / 0.8x**, **암기 카드**(뒤집기·발음·말해 보기 채점), 학습 완료 체크.
- JSON 백업/가져오기(설정에서도 가능).

## 사용 환경 · 제약 (솔직한 안내)

- **Chrome / Edge(Android·PC)** 권장. 음성 인식은 HTTPS에서만 동작하며 iOS Safari는 지원이 제한적입니다.
- 음성 인식(Web Speech API)은 **기본 마이크 입력만** 읽습니다. 줌·팀즈의 탭/시스템 오디오를 자막으로 직접 바꿀 수는 없습니다. 그래서 PC 온라인 미팅은 **스피커로 상대 목소리를 들려주고 마이크로 함께 수음**하는 방식을 안내합니다. 시스템 오디오 공유는 **녹음 파일**에 상대 음성을 더하는 용도입니다.
- 음성 인식은 한 번에 **한 언어만** 듣습니다. 그래서 양방향 자동 모드는 **인식된 문장의 문자**(한글/영문)로 번역 방향을 정하고, 말하는 언어가 바뀔 때는 **⇄ 버튼**(상대/나 버튼, PC는 Tab)으로 주 인식 언어를 바꿔 주세요.
- 구글 번역 공개 엔드포인트는 비공식 경로라 네트워크·정책에 따라 일시적으로 실패할 수 있습니다. 실패 시 문장별 재시도와 안내를 제공합니다.
- 안드로이드에서 녹음과 음성 인식을 동시에 쓰면 기기에 따라 마이크를 한쪽만 잡습니다. 미팅메이트는 위 2번의 안전장치로 자막·번역을 우선 살립니다.
- 기록·표현·녹음은 서버로 전송되지 않고 이 브라우저(로컬 저장소·IndexedDB)에만 남습니다. 사이트를 지우면 함께 사라지므로 백업을 권장합니다.

## 구조

```
meeting-mate/
  build.py                 # 검증 + 단일 index.html/PWA 자산 빌드 (build/)
  src/
    index.template.html    # 셸(탑바·탭바·토스트)
    styles.css             # 다크 슬레이트 + 인디고/에메랄드 테마
    app.js                 # 자막·번역·녹음·요약·스터디·복습 전체 로직
    sw.template.js         # 빌드 해시 캐시 서비스워커
  tools/make_icons.py      # PWA 아이콘(Pillow)
  test/e2e.py              # Playwright 실브라우저 E2E (로컬/라이브)
  test/smoke.py            # 빠른 로컬 스모크
  build/                   # GitHub Pages 배포 산출물 (git 저장소)
```
